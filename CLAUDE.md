# Last Signal (สัญญาณสุดท้าย) — notes for Claude Code

The owner speaks Thai. Reply in Thai, short and plain (they are not a programmer). They test on a phone (landscape) and on a Windows PC.

## What the game is
Browser game, top-down map. Two sides, played against bots (online PvP is a later goal):
- **Humans** — 3-hero squad (player + 2 bots), twin-stick shooter with MOBA skills (Q, F, Space, ultimate E; hold to aim, release to cast), tower defense, capture zones, rescue civilians. Win: destroy the ghost base (รังแม่, `G.zbase`, a `hive` at `HIVE`, 6000 HP, shoots acid, regenerates when left alone). The ghost leader respawns 20 s after dying (boss mode: 15 s at a nest, else at the base).
- **Ghosts/zombies** — two play styles chosen in the loadout:
  - `boss` (default): the player *is* the leader (Spider Queen / Alpha / Plague doctor), walks like a hero, 4 skills, builds nests (B), nests auto-produce 5 unit types, each type has an order: patrol / defend the flag (V) / attack. Queen dies → respawns at a nest (or the base); the base destroyed → lose.
  - `rts`: old commander mode (top-down camera, build/produce/send waves).
- Win for ghosts: destroy the human HQ. The mission panel (`#obj`) is hidden since 2026-11-02 (owner: just destroy the other side's base).

## Files
- `index.html` — the whole game (HTML + CSS + one big `<script>`), ~4k lines, no build step. Open it through a local web server (art is loaded by relative path), e.g. `python -m http.server` in the repo root, then http://localhost:8000.
- `เล่นเกม.bat` — the owner's double-click launcher (ASCII only; runs `tools/play.ps1`, which starts the server, opens the browser and prints the phone address on the home Wi-Fi). Thai text lives in the .ps1 (UTF-8 with BOM) because cmd mangles UTF-8 in .bat files.
- `art/` painted sprites. Characters face RIGHT; the code flips them. Strips are one row of frames, feet-aligned. `art/px/` = optional pixel-art set.
- `fx/` pixelfx sprite effects (MIT, keep `vendor/pixelfx/LICENSE`).
- `vendor/` third-party licences/notices (pixelfx, agent-sprite-forge, three.js). Keep them.
- `docs/prompt-kit.html` — the owner's prompt pack for generating art (ChatGPT images + Google Flow videos).
- `tools/check.sh` — extracts the script and runs `node --check`.
- `tools/sim/sim.js` — headless simulation with a stub DOM: `node tools/sim/sim.js demo|boss|ults|guns` (`guns` = the player fires every gun for 4 s and prints the damage). Run it after gameplay changes; it doubles as a smoke test.
- `tools/video/` — turning a Flow video (flat green/magenta background) into a frame strip: `sqproc.py` (keying, loop search, feet anchor, quantized PNG), `strip2.py` (grid sprite sheet → strip).
- `tools/blender/` — `ls_step1_prepare.py` (Meshy/Tripo GLB → light, upright FBX for Mixamo: drops stray meshes and any bundled rig, welds seam-split vertices, decimates to 20k, bakes the colours onto fresh UVs — plain decimation on the original UVs gives dark cracks), `ls_step2_merge.py` (Mixamo FBX files → one `<hero>_game.glb` with named animations). Both scripts take the hero key (`HERO = '...'` at the top, or `-- <hero>` headless; step 2: `-- <hero> [folder]`); files are `<hero>_mixamo.fbx` / `<hero>_game.glb`. The game loads `art/3d/<key>_game.glb` for every hero whose file exists (`H3.glb`). Blender 5.2 is at `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`; run with `blender -b --factory-startup --python <script>`. In Blender 5.2, node references go stale after `tree.nodes.remove()`; keep names and look nodes up again.
- Node.js is not installed on the owner's PC: `tools/check.sh` / `sim.js` fail there. Check syntax in the browser instead (`.claude/launch.json` → server "game" on port 8000, then `new Function(src)` on the big script).

## Conventions
- Map size: `WS` (world scale, next to `MS`) scales buildings, roads, zones and the whole map; 1.25 since 2026-11-02 (was 1.0). Anything placed in raw world units (like `ZONES`) must be multiplied by `WS`. `MW/48` and `MH/48` should stay whole numbers.
- Keep everything in `index.html` (single file). Patch with exact string replacements; check that each anchor appears once.
- After any edit: `bash tools/check.sh` then `node tools/sim/sim.js ults` / `boss` / `demo 3 480`.
- Balance target: bot-vs-bot demo should be roughly even (humans win about half, matches 4–8 min). Knobs for the ghost side: `ZBAL` (leader HP factor, how fast units gain HP over time, unit walk speed). Last check (2026-11-02, map ×1.25, 12 runs × 720 s, 4 sims in parallel): humans 7–5, average 7.7 min (5.7–9.3). Before the hero systems were added the demo already favoured humans (~11 of 12).
- Mobile first: landscape phone ~844×390. Left half of the screen = move stick, right side = skill arc. Don't cover the middle with UI.
- Art pipeline: owner makes a base image in ChatGPT, then an 8 s Google Flow clip (Frames to Video, same image as first and last frame, flat key-colour background). Use green for pink/magenta characters, magenta otherwise.

## Hero systems (built 2026-11-02 from the owner's design; numbers are first guesses, easy to tune)
- **Gun categories**: every gun in `WEAP` has `cls`; `WCLS` = category name/pros/cons/default weight; `HCLS` = which categories a hero may carry (Storm hmg, Shadow snp+rif, Medic pis, Volt smg, Engineer sg, Trap exp, ปราการ sg). `canUseW(k,w)`: own-category guns, any melee, IV only for Medic. New guns use `look` to borrow another gun's drawing. Gun features: `burst`/`bgap`, `stand` (fires only standing still, .50), `quiet` (zombies notice the hero 110 px later), `heal` (healing dart bullets hit allies), `lob:'mine'` (mine launcher), `heavy` (move-speed factor, falls back to `WCLS[cls].wt` via `wWt`).
- **Hero stats + persistent hero level** (`STK`, `STD`, `heroProf(k)` → `PROF.hs[k]={lv,xp,st}`): 3 points per level, max 30 per stat, level max 30 (`HLMAX`, `needHL`). Effects (`sDmg sStat sSpd sDodge sHp sArm sSpr sRng sCrit sRl`): STR +2% gun dmg & −2.5% status time, AGI +1% speed & +1% dodge (MISS, cap 35%), VIT +3% HP & +1% armor (cap 30%), DEX −3% spread & +2% range, ชำนาญ +1.5% crit (×1.8, "คริ!") & −2% reload. EXP at match end (`heroXP`, win +140). Bots: even spread (`stBal`) — mates at the player's hero level, AI heroes on the ghost side at 60% of the average, demo = 0. The old coin card level is now shown as ★ on cards.
- **In-match levels** (max 15, `MAXLV_H`, `needH`): XP from kills (new), structures, heals, crates, plus 2.4/s. 1 skill point per level (`h.sp`, `h.sk`), skills 1–3 rank ≤4 (rank r needs level 2r−1), ult ranks at 6/11/15 (`ULV`); rank 0 = cannot cast. `castSk` raises `h.mul` by `skPow` during the cast and tags what the cast leaves behind (`pw`, `rk`; read with `PW(o)`), and shortens the cooldown (`skCdk`). Talent points at 5/10/15 (`h.tp`), 4 talents per hero × 2 ranks in `TALS`, stored in `h.up[id]` and read with `U(h,id)`. HUD: green + on skill buttons (Ctrl+key on PC), rank dots, talent button/panel top-left (T). Bots: `botLearn`. The pre-match talent tree `TALH` still exists (renamed "ความถนัดก่อนเกม" in the loadout).
- **Storm kit**: Q grenade (`nade2` = 2/3 grenades) · F passive (`s2.passive`, no aim): 5% per shot to fire a grenade round (`proc`: 7%, then +2% fire rate per proc ×5 via `h.pst`) · Space dodge +30% & speed +25% for 4 s (`h.evT`) · E 6 s no ammo used, fire ×1.5 (`fireK`, `noAmmo`; `leech` lifesteal). The old dash/fan/spin code is left unused (`storm2x`, `storm3x`, `spinT`).
- **Ammo** (`AMMO`, 1 slot, `PROF.h.ammo[k]`, `h.am`, unlocked by hero level 1–17): std, ap, hollow, inc, cryo, shock, exp, bless (×1.4 vs `GHOSTZ`), conc; only round-firing guns (`ammoHit`). **Gun mods** = the 2 old item slots (`ITEMH`, level 2–16): scope, extmag, fastmag, sling, grip, supp, laser, comp; they set `h.mSpr mRng mMag mRl mWt mRate mQuiet mCrit mDmg`.
- **Buildables by role** (`HTW`): Engineer gun/cannon/tesla/sniper/flame/supply · Medic heal/light/flag (new rally flag) · Trap spike · ปราการ bunker (new)/barr/decoy/frost · Storm, Shadow, Volt nothing. No Engineer in the squad → `hqGuns()` places 3–4 free turrets by the HQ (`hqg`, level up at 4 and 7 min). Build keys 1–6.
- **ปราการ** (`tank`, 7th hero, code-drawn): passive −20% damage and zombies prefer him · Q riot shield 4 s (front −90%, else −30%; `hurtH` now takes the attacker as 3rd arg) · F sandbag bunker (a `bunker` tower with `sk:1`; talents `bmg` MG, `bunk2` more bunkers) · Space taunt 3 s (`z.tauntT`, `z.taunter`) · E steel dome 6 s (`G.domes`, zombies pushed out, heroes inside −60%). Decision: he shares the shotgun category with the Engineer; the draft's "tool guns" category for the Engineer (and net gun for Trap) was not built.

The spine twist is undone before each `mixer.update(0)` (`M.sq`): the mixer skips bones whose value did not change (e.g. before a clip's first key), which would twist twice. Game code: `H3.glb`, `useGLB` (toon material, ink outline, size measured from skinned vertices — `Box3.setFromObject` is wrong for skinned meshes, hips locked in place so non-"In Place" clips stay in frame), `clip3D` (clip from hero state), `pose3DGLB` (gun in right hand pointing at left hand). The camera is tilted, so `yaw3D` turns the model until its forward line lands on the aim angle on screen. While firing, the barrel is turned onto the aim (`s.dl` turns the whole body when standing; `s.dlS` twists the spine when moving). Moving + shooting/reloading/throwing plays legs from `run` and the upper body from the action (clips split at the Spine bone: `runl`, `shootu`, `reloadu`, `throwu`); running away from the aim plays the run backwards. Shots start at the 3D muzzle: `draw3DHero` stores `h._mz`, `muzzleOf(h,ml)` gives the real start point on the aim line (hits unchanged) plus `qx,qy` = where it is drawn (chest height, a bit to the side); bullets carry `qx,qy` for drawing only.
