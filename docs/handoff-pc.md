# ส่งต่องานไปเครื่อง PC (2026-11-08)

เจ้าของจะคุยต่อกับ Claude Code บนเครื่อง PC ไฟล์นี้สรุปว่างานอยู่ตรงไหน และจะทำอะไรต่อ
(Claude บน PC: read this file and CLAUDE.md first. Reply in Thai, short and plain.)

## เริ่มบน PC
1. เปิดโฟลเดอร์โปรเจกต์ `last-signal-pvp` แล้วดึงงานล่าสุด: `git pull origin main` (ทุกอย่างอยู่บน main แล้ว)
2. ลองเกมในเครื่อง: ดับเบิลคลิก `เล่นเกม.bat` หรือ `python -m http.server` ในโฟลเดอร์โปรเจกต์ แล้วเปิด http://localhost:8000/pack.html
3. เครื่อง PC ไม่มี Node.js: เช็กโค้ดในเบราว์เซอร์แทน (ดู CLAUDE.md)

## PixelLab บน PC
- ใส่รหัสใน Claude Code ของ PC ด้วยคำสั่งนี้ (ใช้ **รหัสใหม่** จากเว็บ PixelLab และลบรหัสเก่าที่เคยพิมพ์ในแชททิ้ง):
  `claude mcp add --transport http pixellab https://api.pixellab.ai/mcp --header "Authorization: Bearer <รหัสใหม่>"`
- บัญชีตอนนี้เป็น **ทดลอง (trial)**: เหลือประมาณ **19.25 เครดิต** ได้เพิ่มวันละ 5 · ทำได้ **ทีละ 1 งาน**
- ราคาที่ใช้จริง: สร้างตัวจากรูปของเรา 1–2 เครดิต (นำเข้ารูปเองทุกทิศ = 0.25) · ท่าแบบพิมพ์คำสั่ง (PixMiniMax) 8 ภาพ = 1 · 12–16 ภาพ = 2 · 24 ภาพ = 3 (ต่อทิศ, ขนาด 64/128/256 ราคาเท่ากัน)
- **บทเรียน:** ก่อนเจนท่า ส่งรูปตั้งต้นให้เจ้าของดูก่อนทุกครั้ง (รอบแรกรูปหันขวาเป็นมุมเฉียงเข้ากล้อง ท่าเลยหันหน้าเข้ากล้อง เสียเครดิต) · แบบพิมพ์คำสั่งดีกว่าแบบกระดูก (ถูกกว่า สวยกว่า) · ตัวที่สร้างจากรูปของเราเองสีไม่เพี้ยน · PixMiniMax ชอบแถมก้อนควันเทา: `tools/art/pixellab_sheet.py --smoke` ลบให้

Dimraeth = แอคชัน RPG ภาพพิกเซล มองจากบนเฉียง สู้แบบ Souls-lite (ฟันเป็นจังหวะ แถบพลัง กลิ้งหลบ) ร่วมเล่น 1–8 คน สร้างฐาน คราฟต์
ภาพที่เจ้าของชอบ: Realms of Pixel (จิบิพิกเซลเล็ก สีน้อย เส้นขอบ มองจากบนเฉียง ช่องข้าวหลามตัด ฉากกลางวันสว่าง)

ข้อเสนอที่ยังรอเจ้าของตอบ:
1. **ต้นแบบหน้าใหม่ (ไม่เสียเครดิต):** บังคับหงอคง 8 ทิศ (คอม WASD + เมาส์ / มือถือจอยซ้าย ปุ่มขวา) · ตีต่อเนื่อง 3 จังหวะ · กลิ้งหลบ · แถบพลัง · ภาพค้างตอนโดน · มอนวิ่งเข้ามา · เริ่มจากรูปนิ่ง 8 ทิศของ "Sun Wukong chibi 64"
2. **ท่า (ใช้เครดิต):** ทำ 5 ทิศ (south, south-east, east, north-east, north) อีก 3 ทิศพลิกเอา · วิ่ง + ตี + กลิ้ง ≈ 15 เครดิต (ท่าละ ~1 ต่อทิศ ที่ 8 ภาพ) · แนะนำวิ่ง + ตีก่อน
3. ส่งรูปตั้งต้นทิศ south-east ให้เจ้าของดูแล้ว (หันเฉียงเห็นหน้า ถือกระบอง) รอเจ้าของบอกว่าโอเค
