# หมา vs แมว: ศึกษาระบบ และข้อเสนอ (ร่าง 2026-11-12)

เจ้าของสั่งก่อนนอน: "ศึกษาระบบ" เอกสารนี้สรุปว่า 3 เกมต้นแบบทำงานยังไง แล้วเสนอวิธีเอามารวมเป็นเกมของเรา
**ยังไม่ใช่กติกาที่ตัดสินแล้ว** ทุกข้อแก้ได้ ข้อมูลเกมต้นแบบเขียนจากความรู้ของ Claude ไม่ได้เปิดเกมเช็คสด ตัวเลขละเอียดอาจคลาดได้

สิ่งที่เจ้าของตัดสินแล้ว (ห้ามเปลี่ยนเอง):
- ธีมหมา vs แมว ตัวละ 1 สายพันธุ์ 1 คาแรคเตอร์
- บอร์ดแบบ Lucky Defense: มอนเดินวนรอบบอร์ด ตัวละครยืนประจำแท่น ("กันบ้าน ไม่ได้ไปบุก")
- รวมตัวแบบ TFT: 3 ตัวเหมือนกัน → 2 ดาว, 3 ตัว 2 ดาว → 3 ดาว
- โชว์แต่บอร์ดตัวเอง ซูมออก 1.5 บอร์ด 7×4
- เก็บม้านั่งไว้
- ช่องว่างใต้บอร์ด = กระเป๋าแบบ Backpack ไอเทมในกระเป๋า "ใช้ด้วยกันหมด" เป็นลูกเล่นของเกม
- ท่าโจมตีและเอฟเฟกต์โจมตีใช้ของ PixelLab ทุกตัว เอฟเฟกต์สกิลใช้จากคลิป/ไฟล์ที่เจ้าของเจน

## 1. เกมต้นแบบทำงานยังไง

### 1.1 Lucky Defense (บอร์ด + ความตื่นเต้น)
- 2 คนเล่นพร้อมกัน คนละบอร์ด มอนเดินวนเป็นวงรอบบอร์ดไม่มีวันถึงปลายทาง
- **แพ้เมื่อมอนสะสมบนทางเดินเกินจำนวน** (ประมาณ 100 ตัว) เกมจึงเป็นการแข่ง "ฆ่าให้ทัน"
- กดอัญเชิญได้ตัวสุ่ม ราคาแพงขึ้นเรื่อย ๆ ตัวเหมือนกัน 3 ตัวรวมเป็นขั้นสูงขึ้น
- มี "ดวง": กดเสี่ยงโชคเพื่อได้ตัวระดับสูง และมีตัวพิเศษที่ต้องใช้สูตร (ตัว A + B + C)
- มีบอสเป็นระยะ ฆ่าไม่ทันเวลา = แพ้
- จุดสนุก: เร็ว ลุ้นดวง เห็นผลทันที เล่นจบใน 10-15 นาที

### 1.2 TFT (ร้านค้า + รวมดาว + ม้านั่ง)
- ทุกรอบร้านสุ่มตัวละครมา 5 ใบ ซื้อด้วยทอง กด "สุ่มใหม่" ได้ (เสียทอง)
- ตัวละครมีราคา 1-5 ทอง ตัวแพงเก่งกว่าและออกยากกว่า
- **เลเวลผู้เล่น**: ซื้อ EXP เพื่อเพิ่มเลเวล เลเวลสูง = วางตัวได้มากขึ้น และร้านออกตัวแพงบ่อยขึ้น
- **ดอกเบี้ย**: เก็บทองไว้ ได้ทองเพิ่มทุกรอบ → ต้องเลือกระหว่างใช้เลยกับออม
- **ม้านั่ง**: ที่พักตัวที่ยังไม่ลงสนาม ใช้เก็บตัวรอรวมดาว
- **เผ่า/อาชีพ (synergy)**: วางตัวกลุ่มเดียวกันครบจำนวน ได้โบนัสทั้งทีม
- จุดสนุก: วางแผนเศรษฐกิจ ตัดสินใจทุกรอบ ลุ้นของในร้าน

### 1.3 Backpack Battles (กระเป๋า)
- มีกระเป๋าเป็นตาราง ไอเทมแต่ละชิ้นมี**รูปทรง** (1 ช่อง, 1×2, 2×2, ตัว L ...) ต้องจัดให้ลง
- ซื้อ "ถุงเสริม" เพื่อขยายพื้นที่กระเป๋า
- **ตำแหน่งสำคัญ**: ไอเทมบางชิ้นให้โบนัสกับของที่อยู่ติดกัน (มีดาว/ลูกศรชี้ทิศที่ส่งผล)
- **รวมของ**: ของบางคู่วางติดกันแล้วรวมเป็นของใหม่ที่ดีกว่าเมื่อจบรอบ
- ร้านสุ่มของทุกรอบ ล็อกของไว้รอบหน้าได้ ขายของคืนได้
- จุดสนุก: เกมปริศนาจัดกระเป๋า "ยัดยังไงให้ได้มากสุด และวางติดกันให้ถูกคู่"

## 2. เอามารวมกันยังไง (ข้อเสนอ)

แนวคิดหลัก: **บอร์ดบน = กำลังรบ, กระเป๋าล่าง = พลังเสริมของทั้งทีม**
คนเล่นตัดสินใจ 2 เรื่องตลอดเกม: ทองก้อนนี้จะซื้อ "ตัว" หรือซื้อ "ของ"

### 2.1 หนึ่งรอบ (ประมาณ 30-40 วินาที)
1. **ช่วงเตรียม (10-15 วิ)**: ร้านเปิด ซื้อตัว/ของ จัดกระเป๋า ย้ายตัวบนบอร์ด
2. **ช่วงเวฟ (20-25 วิ)**: มอนออกมาเดินวน ตัวละครตีเอง ฆ่าได้ได้ทอง
3. จบเวฟ: ได้ทองประจำรอบ + ดอกเบี้ย ร้านสุ่มใหม่

### 2.2 แพ้ชนะ
- มอนสะสมบนทางเดินถึง 100 ตัว = แพ้ (แบบ Lucky Defense)
- เล่น 2 คน (หมา vs แมว): ใครอยู่ได้นานกว่าชนะ
- เสนอเพิ่ม: ฆ่ามอนครบจำนวน → ส่ง "มอนพิเศษ" ไปบอร์ดอีกฝั่ง ทำให้สองฝั่งได้กวนกัน

### 2.3 ตัวละคร (แบบ TFT)
- ร้าน 5 ใบ ราคา 1-4 ทองตามระดับความหายาก
- 3 ตัวเหมือนกันรวมดาวอัตโนมัติ (รวมทั้งที่อยู่บนม้านั่ง)
- ม้านั่ง 8 ช่อง (ตามภาพจำลองตอนนี้)
- จำนวนตัวบนบอร์ดจำกัดด้วยเลเวลผู้เล่น (เช่น เลเวล 1 = 3 ตัว สูงสุด ~12 ตัว) บอร์ด 28 ช่องจึงมีที่ให้เลือกตำแหน่ง
- **ตำแหน่งมีความหมาย**: ตัวตีใกล้ (ชิบะ) ควรอยู่ขอบบอร์ดติดทางเดิน ตัวยิงไกล (คอร์กี้ แมวนินจา) อยู่ตรงกลางได้

### 2.4 กระเป๋า "ใช้ด้วยกันหมด" (ลูกเล่นหลัก)
- กระเป๋าใต้บอร์ด เริ่ม 6×3 ช่อง ซื้อถุงเสริมขยายได้
- ไอเทมมีรูปทรง ต้องจัดให้ลง ลากวาง แตะเพื่อหมุน (ระบบนี้เคยทำไว้แล้วใน `docs/gem-mock.html` เอามาใช้ต่อได้)
- **ไอเทมทุกชิ้นให้ผลกับตัวละครทุกตัวบนบอร์ด** ไม่ต้องใส่รายตัว → เข้าใจง่ายกว่า TFT มาก
- ความลึกมาจาก 3 อย่าง:
  1. **ที่จำกัด**: ของดีมักรูปทรงใหญ่/แปลก ต้องเลือกว่าจะเก็บชิ้นไหน
  2. **วางติดกันได้โบนัส**: เช่น กระดูก (+โจมตี) ติดกับ ชามข้าว (+เลือด) → ทั้งคู่แรงขึ้น
  3. **ของเฉพาะกลุ่ม**: บางชิ้นให้ผลเฉพาะ "สายดาบ" หรือ "สายยิง" → เชื่อมกับการเลือกตัวละคร
- ตัวอย่างไอเทมธีมหมา (ฝั่งแมวมีชุดของตัวเอง):

| ไอเทม | รูปทรง | ผล (ทั้งทีม) |
|---|---|---|
| กระดูก | 1×2 | โจมตี +10% |
| ปลอกคอหนาม | 1×1 | คริติคอล +5% |
| ชามข้าว | 2×2 | ตีเร็ว +15% |
| ลูกบอลยาง | 1×1 | ทุกการตีครั้งที่ 5 เด้งไปโดนมอนอีกตัว |
| สายจูง | 1×3 | ระยะตี +1 ช่อง |
| ขนมหมา | 1×1 | ของที่อยู่ติดกันแรงขึ้น 25% |
| เบาะนอน | 2×3 | สกิลชาร์จเร็ว +20% |
| ป้ายชื่อทอง | ตัว L | ฆ่ามอนได้ทองเพิ่ม |

### 2.5 เศรษฐกิจ (ทองก้อนเดียว ใช้ 4 ทาง)
- ซื้อตัวละคร · ซื้อไอเทม/ถุงเสริม · สุ่มร้านใหม่ · ซื้อเลเวล
- ร้านเดียวขายทั้งตัวและของปนกัน (เสนอ: 3 ใบเป็นตัว 2 ใบเป็นของ) → ไม่ต้องมีหลายหน้าจอ
- ดอกเบี้ยแบบ TFT อย่างเบา ๆ (สูงสุด +3) ให้มีเหตุผลออมทอง

### 2.6 เล่นได้นาน (ระบบนอกแมตช์)
เจ้าของเคยบอกว่า "คนเล่นต้องมีอะไรให้อัพ เล่นไปนาน ๆ"
- สะสมตัวละคร: ปลดล็อกสายพันธุ์ใหม่เข้ากองไพ่ของตัวเอง (ในแมตช์ร้านสุ่มจากกองที่เรามี)
- เลเวลตัวละครถาวร: เล่นแล้วได้เศษ เอาไปอัพค่าพลังพื้นฐานทีละนิด
- ปลดล็อกไอเทมกระเป๋าแบบใหม่
- ภารกิจรายวัน อันดับ

## 3. คำถามที่ต้องให้เจ้าของตัดสิน

1. **ไอเทมได้มาจากไหน**: (ก) ซื้อในร้านเดียวกับตัวละคร (ข้อเสนอ) (ข) มอน/บอสดรอป (ค) ทั้งสองทาง
2. **ได้ตัวละครยังไง**: ร้านเลือกซื้อแบบ TFT (ข้อเสนอ เพราะเจ้าของเลือกระบบรวมดาวแบบ TFT) หรือกดสุ่มแบบ Lucky Defense
3. **วางตัวได้กี่ตัว**: จำกัดตามเลเวล (ข้อเสนอ) หรือเต็ม 28 ช่อง
4. **หมา vs แมวเจอกันยังไง**: แข่งกันอยู่รอด + ส่งมอนไปกวน (ข้อเสนอ) หรือแบบอื่น
5. **เล่นกับบอทก่อน หรือออนไลน์ตั้งแต่แรก**: เสนอบอทก่อนเหมือนทุกเกมที่ทำมา
6. **แนวจอ**: ตั้ง (ตามภาพจำลองตอนนี้)

## 4. ถ้าจะเริ่มทำเป็นเกมเล่นได้ (ลำดับที่เสนอ)

1. ไฟล์เกมเดียว (เช่น `dogcat.html`) บอร์ด 7×4 + ทางวน + มอนเดิน + ตัวละครตีเอง ใช้ชิบะ คอร์กี้ที่มีแล้ว
2. ร้าน 5 ใบ + ม้านั่ง + รวมดาว
3. กระเป๋าลากวาง + ไอเทม 8 ชิ้นข้างบน
4. บอทฝั่งแมว + แพ้ชนะ
5. ค่อยเติมตัวละคร (ต้องมีอย่างน้อย ~8 ตัวต่อฝั่งถึงจะสนุก ตอนนี้มีหมา 2 แมว 1)

ของที่มีพร้อมใช้แล้ว: ชิบะ / คอร์กี้ / แมวนินจา อย่างละ 3 ดาว (ท่ายืน + ท่าโจมตี), มอน 40+ ชนิดจากเกมแอ็กชัน,
พื้นและของตกแต่ง, เอฟเฟกต์สกิลแมว 2 อัน (`fx/cat3_boom`, `fx/cat_storm`), ภาพจำลองฉาก `art/incoming/dogcat/tw_scene.png`
