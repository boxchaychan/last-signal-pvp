ชุดคำสั่งเจนรูป "ฟอร์มดึกดำบรรพ์" สำหรับ Codex (หรือ AI เจนรูปตัวอื่น)

ในโฟลเดอร์นี้มี
- PROMPT.md = คำสั่งยาวแบบละเอียด (ภาษาอังกฤษ) อธิบายงานทั้งหมด สไตล์ กฎ และคำสั่งของแต่ละตัว
- refs/ = รูปแนบ: 00 = รูปตัวอย่างแทนแอนคิโลซอรัส (สไตล์ที่ต้องการ) · 01-05 = ร่างทองของ นิล ฟ้า ราตรี จันทร์ หมอก (ไว้ให้หน้าเหมือนเดิม)
- prompts/ = คำสั่งแยกทีละตัว ก๊อปไปวางได้เลย (มีแบบ 4 ตัวเลือกท้ายไฟล์ด้วย)

วิธีใช้กับ Codex
1. แตกไฟล์ zip แล้วแนบทั้งโฟลเดอร์ (หรือแนบ PROMPT.md + รูปทั้งหมดใน refs) ให้ Codex
2. พิมพ์: Read PROMPT.md carefully and follow it. Generate the 5 pictures.
3. ได้รูปแล้ว ส่งไฟล์ PNG ทั้งหมดมาให้ Claude ในแชต (ส่งเป็นไฟล์หรือ zip) Claude จะแปลงเป็นพิกเซลแล้วใส่เกมให้

ถ้า Codex เจนรูปไม่ได้: เปิด ChatGPT แชตใหม่ทีละตัว แนบ 2 รูป (ร่างทองของตัวนั้น + รูป 00 ตัวอย่างแทน) แล้วก๊อปคำสั่งในไฟล์ prompts/ ของตัวนั้นไปวาง
