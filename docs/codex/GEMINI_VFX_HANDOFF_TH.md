# งานสำหรับ Gemini: ท่าโจมตีและ VFX ของ Lucky Pantheon

ส่งงานเป็นไฟล์ ZIP หนึ่งไฟล์ โดยไม่ต้องแก้ระบบเกมหรือ HTML หลัก

## ขนาดในเกม

- จอเกมตรรกะ: 585 × 1266 px
- ตาราง: 6 × 3 รวม 18 ช่อง
- ตัวละครปกติบนจอ: สูง 72–90 px
- ตัวละคร Mythic: สูงไม่เกิน 100 px
- กล้อง: ด้านหน้ามุมสูงเล็กน้อยแบบเกมมือถือ

## ไฟล์ที่ต้องส่งต่อหนึ่งตัวละคร

- `idle.png`: sprite sheet 6 เฟรม
- `attack.png`: sprite sheet 8 เฟรม
- `skill.png`: sprite sheet 10–12 เฟรม
- `portrait.png`: 512 × 512 px
- พื้นหลังโปร่งใส ไม่มีเงาพื้น ไม่มีตัวหนังสือ
- ทุกเฟรมขนาดเท่ากันและเรียงซ้ายไปขวา
- แนบ `meta.json` ระบุ `frameWidth`, `frameHeight`, `frames`, `fps`, `hitFrame`, `originX`, `originY`

## VFX ที่ต้องส่ง

- กรีก: สายฟ้าลูกโซ่ 3 เป้าหมาย
- นอร์ส: ค้อนกระแทกและวงสตัน
- อียิปต์: ระเบิดพลังสุริยะเป็นวง
- เอเชีย: ฟัน/พุ่งเร็วและรอยดาบ
- ส่งเป็น sprite sheet พื้นโปร่งใส ขนาดเฟรม 128 × 128 หรือ 256 × 256 px
- ห้ามใส่ตัวเลขดาเมจ ตัวหนังสือ UI หรือฉากหลังใน VFX

```text
gemini-vfx/

```
