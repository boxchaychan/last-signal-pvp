# ระบบหมวดหมู่สกิล + รวมสกิล — แผน

เจ้าของ 2026-11-09: "เตรียมระบบรวมสกิล ตอนนี้สกิลเราไม่มีหมวดหมู่ ให้จัดสกิลเป็นหมวดหมู่ เช่น สกิลกดใส่ตัวล็อคเป้า สกิลลงพื้นแบบวงกลม แบบแนวยาว
ตรง แบบกรวย เพื่อให้เราเอาสกิลมาต่อกันได้ เพราะสกิลเริ่มเยอะ โดยจะมีคลาส 2"

## 1. หมวด "รูปแบบ" (สกิลออกไปยังไง) — สกิลหนึ่งมี 1 รูปแบบหลัก
| รหัส | ชื่อ | ความหมาย | ปุ่ม |
|---|---|---|---|
| self | ใส่ตัวเอง | บัพ/ฮีล/โล่ กดแล้วติดตัวทันที | กดทีเดียว |
| lock | ล็อคเป้า | เลือกมอนใกล้สุด/ที่เล็ง วิ่งเข้าหาเอง (เด้งต่อได้) | กดทีเดียว |
| circle | วงกลมบนพื้น | เล็งจุด ลงเป็นวง | ลากเล็ง |
| line | แนวยาว | จากตัวพุ่งเป็นเส้นตรงยาว ทะลุทุกตัว | ลากเล็งทิศ |
| shot | ยิงตรง | ลูกเดียวพุ่งไป โดนตัวแรก (ระเบิดเป็นวงได้) | ลากเล็งทิศ |
| cone | กรวย | หน้าตัว กว้างเป็นพัด | ลากเล็งทิศ |
| around | รอบตัว | วงรอบตัวเอง | กดทีเดียว / กดค้าง |
| move | เคลื่อนที่ | พุ่ง/วาร์ป/กระโดด (อาจมีดาเมจตอนลง) | ลากเล็ง |
| trap | วางกับดัก | วางไว้ มอนเข้ามาแล้วทำงาน | ลากเล็ง |

## 2. ป้าย "ผล" (สกิลทำอะไร) — มีได้หลายป้าย
ดาเมจ · คุม (มึน/ตรึง/ช้า/ตาบอด/แช่แข็ง) · ดึง/ผลัก · บัพ · ดีบัพ (เปราะ/อ่อนแรง) · ฮีล · โล่ · ชาร์จ (กดค้าง) · ทำต่อเนื่อง (กดค้าง)

## 4. "รวมสกิล / เอาสกิลมาต่อกัน" — 3 แบบให้เลือก (ยังไม่ตัดสิน)
A. **คลังสกิล + จัดปุ่มเอง**: คลาส 1 + คลาส 2 มีสกิลรวมกันเยอะ เลือกใส่ปุ่ม Q E R F Z X ได้ 6 อัน หน้าต่างเลือกกรองตามหมวด (ข้อ 1–2)
B. **คอมโบต่อเนื่อง**: ใช้สกิล A แล้วตามด้วย B ภายใน ~1.5 วิ ได้ผลเพิ่มตามคู่หมวด เช่น
   คุม (มึน/ตรึง) → circle = ดาเมจ +30% · move → cone/around = ไม่เสียแรง · ดีบัพ → line = ทะลุเกราะ · trap → circle = กับดักระเบิด
C. **ผสมสกิลเป็นสกิลใหม่**: เอา 2 สกิลมาผสมในหน้าต่าง ได้สกิลใหม่ที่รูปแบบของอันแรก + ผลของอันที่สอง (เช่น ลูกไฟ shot + ผลแช่แข็ง = ลูกน้ำแข็ง) ยากสุด ต้องมีภาพเอฟเฟกต์ใหม่ตาม

## 5. ในโค้ด (เตรียมไว้)
- ตาราง `SKCAT[hero][k] = {shape, tags}` ตามข้อ 3 ใช้ทั้งหน้าต่างสกิล คอมโบ และคลาส 2
- ปุ่มเล็ง: รูปแบบเดียวกันใช้ตัวเล็งเดียวกัน (วง/เส้น/กรวย) ตอนนี้เล็งได้แค่ "จุด" อย่างเดียว ต้องเพิ่มตัวเล็งเส้นกับกรวย
- คลาส 2 (เลเวล 50): เพิ่มสกิลเข้าคลังของอาชีพนั้น ใช้หมวดเดียวกัน
- **ตื่นสกิล (Awaken)** (เจ้าของ 2026-11-09): คลาส 2 เอาสกิลคลาส 1 มา 1 อันแล้วตื่นเป็นร่างแรงขึ้น หน้าตาเปลี่ยนตามโทนคลาส 2 เบอร์เซิร์กเกอร์ = X คลั่ง → ร่างคลั่งโลหิต (`docs/berserker.md`)
