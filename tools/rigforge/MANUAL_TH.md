# คู่มือการใช้งาน RigForge 2D — เครื่องมือสร้างแอนิเมชัน 2D สำหรับเกม

**RigForge 2D** เป็นเครื่องมือทำแอนิเมชัน 2D แบบโครงกระดูก (Skeletal Animation) และตาข่าย (Mesh Deformation) ที่รันได้ทันทีบนเว็บเบราว์เซอร์ (Chrome, Edge, Safari) โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม รองรับการส่งออกเป็น **Sprite Sheet (.png)** และ **Atlas/Rig (.json)** เพื่อนำไปใช้ใน **Unity, Godot 4 และ Phaser 3** ได้ทันที

---

## 1. การเริ่มต้นใช้งาน
1. แตกไฟล์ `RigForge_2D_Studio_Pack.zip` ลงในโฟลเดอร์บนเครื่อง
2. ดับเบิลคลิกเปิดไฟล์ **`rigforge_2d.html`** ด้วยเว็บเบราว์เซอร์ (แนะนำ Google Chrome หรือ Microsoft Edge)
3. หน้าจอจะโหลดตัวละครตัวอย่างพร้อมใช้งาน 3 โหมดที่แถบด้านบน:
   - **ซุส (16 ชิ้น + ปาสายฟ้า):** ตัวละครแยกชิ้นส่วนพร้อมท่าปาสายฟ้าแบบหลุดออกจากมือจริง
   - **โพไซดอน (17 ชิ้น):** ตัวละครแยกชิ้นส่วนพร้อมผ้าคลุมพลิ้ว (Mesh) และตรีศูล
   - **ภาพเดียว Mesh:** โหมดดัดตาข่ายจากภาพตัวละครเต็มตัว 1 ภาพโดยไม่ต้องตัดแยกชิ้น

---

## 2. ส่วนประกอบหลักของหน้าจอ
- **แถบด้านบนสุด:** สลับโหมด **แต่งท่า & คีย์เฟรม** กับ **ทดสอบในฉากเกม**, ปุ่มย้อนกลับ/ทำซ้ำ (`Ctrl+Z` / `Ctrl+Y`), ปุ่ม **บันทึก / เปิดโปรเจกต์ (.json)**, ปุ่ม **นำเข้าภาพใหม่**, และปุ่ม **ส่งออกเกม**
- **แถบคลิปแอนิเมชัน:** สลับระหว่างท่ามาตรฐาน (`ปาสายฟ้า`, `ฟาดสายฟ้า`, `อัลติ`, `ยืนเด้งดึ๋ง`, `เดินเด้ง`, `โดนตี`) ปรับจังหวะการเคลื่อนไหว (`ฟาดคม`, `เด้งดึ๋ง`, `นุ่มนวล`) หรือกด **+ สร้างคลิปใหม่**
- **แถบซ้าย (โครงกระดูก):** รายชื่อชิ้นส่วนทั้งหมดตามลำดับแม่-ลูก คลิกเพื่อเลือกชิ้นส่วน หรือกดรูปดวงตาเพื่อซ่อน/แสดงชิ้นส่วนนั้น
- **หน้าจอกลาง (Viewport):** พื้นที่แสดงและจัดท่าตัวละคร รองรับการซูมด้วยลูกกลิ้งเมาส์สูงสุด **300%**
- **แถบขวา (Inspector):** ปรับค่าละเอียดของชิ้นส่วนที่เลือก ทั้งมุมหมุน (`-1° / +1°`), ยืด-หด X/Y (Squash & Stretch), ตำแหน่ง X/Y, ขนาด, ลำดับชั้น Z-Order, ปุ่มจัดท่าด่วน 1 คลิก, ตัวลบเส้นรอยต่อ และกราฟความเร็ว **Bezier Graph**
- **แถบล่าง (Timeline):** เล่น/หยุด (`Space`), ข้ามทีละคีย์เฟรม (`< / >`), ปรับเวลาคลิป (วินาที), คัดลอก/วางท่า, เปิด **Auto-Key**, และลากจุดคีย์เฟรม (ข้าวหลามตัด) เพื่อปรับจังหวะเร็ว-ช้า

## 3. ขั้นตอนการจัดท่าและสร้างแอนิเมชันเอง (Workshop)

### ขั้นที่ 1: จัดตำแหน่งโครงกระดูก (โหมด Setup)
1. กดสลับปุ่มมุมซ้ายบนของแคนวาสเป็น **`Setup`** (ระบบจะเปิด **ภาพดราฟต้นแบบ** โปร่งแสงด้านหลังให้อัตโนมัติ)
2. คลิกเลือกชิ้นส่วนที่ต้องการแล้วลากจัดตำแหน่งให้ตรงกับภาพต้นแบบโดยไม่กระทบคีย์เฟรมแอนิเมชัน
3. หากชิ้นส่วนไหนซ้อนทับผิดลำดับ ให้ปรับที่ **ลำดับชั้น (Z-Order)** ทางแถบขวา (`-` เอาลงล่าง / `+` เอาขึ้นบน)

กด **ซ่อนข้อต่อ** ข้างปุ่ม Setup เมื่อต้องการดูท่าเต็มตัว ปุ่มนี้ซ่อนเส้นกระดูก วงหมุน และจุดจับ พร้อมพักการลากบนตัวละคร กด **แสดงข้อต่อ** เพื่อกลับมาแก้ต่อด้วยตัวช่วยชุดเดิม รูปตาในรายชื่อกระดูกใช้ซ่อนภาพชิ้นนั้นทั้งคลิป ส่วน **Slot Key** ใช้กำหนดจังหวะซ่อน เช่น เฟรมที่สายฟ้าหลุดจากมือ

### ขั้นที่ 2: จัดท่าด้วย 2-Bone IK หรือวงแหวนหมุน (โหมด Animate)
1. สลับกลับมาที่โหมด **`Animate`** และตรวจสอบให้ปุ่ม **`Auto-Key`** เปิดอยู่ (ไฟสีชมพูกะพริบ)
2. กด **หยุด (`Space`)** แล้วเลื่อนเส้นเวลาสีฟ้าไปยังตำแหน่งที่ต้องการ (เช่น `0%`, `25%`, `50%`)
3. จัดท่าได้ 3 วิธี:
   - **แบบง่ายสุด (2-Bone IK):** ลากจุดกากบาทสีชมพูที่มือหรือเท้า ข้อศอกและหัวเข่าจะงอตามอัตโนมัติ
   - **แบบหมุนทีละข้อต่อ:** คลิกที่ชิ้นส่วนแล้วลาก **วงแหวนหมุนสีฟ้า** บนตัวละคร หรือกดปุ่ม `-1° / +1°` ทางแถบขวาเพื่อเก็บรายละเอียด
   - **แบบด่วน 1 คลิก:** กดปุ่ม **จัดท่าด่วน (ยืนตรง / ง้างปา / ขว้าง! / กระโดด)** เพื่อวางโครงท่าเริ่มต้นแล้วค่อยปรับเพิ่ม
4. **การซ่อน/แสดงอาวุธเฉพาะเฟรม (Slot Key):** เช่น ตอนปาสายฟ้าออกจากมือ ให้เลื่อนไปยังจังหวะปล่อยมือ เลือกชิ้นอาวุธ แล้วกด **ซ่อน/แสดงชิ้นนี้ในเฟรมนี้ (Slot Key)**
5. **ปรับความลื่นและแรงกระแทก:** ลากจุดสีฟ้า/ชมพูบน **กราฟความเร็ว (Bezier Graph)** มุมขวาล่าง (ดึงจุดให้สูงเกินเส้นกรอบบนจะเกิดแรงเด้งแบบการ์ตูน Overshoot)

---

## 4. การนำเข้าตัวละครใหม่ของตัวเอง
1. กดปุ่ม **นำเข้าภาพใหม่ (Chroma Key)** ด้านบนขวา
2. เลือกวิธีที่เหมาะกับภาพของคุณ:
   - **ภาพแยกชิ้นส่วนบนพื้นสีเขียว (`#00FF00`):** กด **อัปโหลดภาพแยกชิ้นส่วน** ระบบจะลบพื้นสีเขียวและตัดแยกทุกชิ้นให้อัตโนมัติ (แนะนำให้ติ๊ก **ลบเส้นขอบข้อต่ออัตโนมัติ** ไว้ด้วย) จากนั้นเลือกชื่อกระดูกปลายทางแล้วคลิกชิ้นส่วนที่ตัดได้เพื่อสวมทับ
   - **ภาพเต็มตัวสำหรับทาบจัดตำแหน่ง:** กด **อัปโหลดภาพดราฟต้นแบบ** เพื่อใช้เป็นเงาเทียบในโหมด Setup
   - **ภาพตัวละครเต็มตัว 1 รูป (ไม่แยกชิ้น):** กด **อัปโหลดภาพเดี่ยว** ระบบจะลบพื้นหลังสีขาวหรือสีเขียวรอบนอกให้อัตโนมัติและเข้าสู่โหมด **ภาพเดียว Mesh** ทันที

> **เคล็ดลับการออกแบบตัวละคร 2D ให้ต่อกระดูกเนียน:** ควรออกแบบให้มี **เกราะไหล่, แขนเสื้อ, ปลอกแขน, หรือเข็มขัด** ปิดทับบริเวณจุดหมุนข้อต่อ จะช่วยให้หมุนแขนขาได้ทุกองศาโดยไม่เห็นรอยต่อ (ลองเปิด/ปิดปุ่ม **เกราะไหล่** ในเมนู **ตัวช่วยละเอียด ▾** เพื่อดูความต่าง)

## 5. การทดสอบในฉากเกมและส่งออกใช้งานจริง
1. กดปุ่ม **ทดสอบในฉากเกม** ด้านบนเพื่อดูตัวละครยิงโจมตีและปล่อยท่าไม้ตายใส่ฝูงมอนสเตอร์ในฉาก Auto-Battler (กด `A / D` เดิน, `W` เสกเวฟมอนสเตอร์, `F` ปล่อยอัลติ)
2. กดปุ่ม **ส่งออกเกม (Sprite Sheet)** เมื่อพร้อมใช้งาน:
   - ตั้งชื่อไฟล์, จำนวนเฟรม (`8` หรือ `12` เฟรมแนะนำสำหรับเกมมือถือ), และขนาดต่อเฟรม (`256×256 px` หรือ `512×512 px`)
   - ติ๊ก **รวมทุกท่าเป็นแผ่นเดียว (All-in-One Multi-Row Sheet)** หากต้องการรวมทุกคลิปแอนิเมชันไว้ในไฟล์ PNG แผ่นเดียว
   - กด **ดาวน์โหลด Sprite Sheet (.png)** และ **ดาวน์โหลด Rig & Atlas (.json)**
   - เลือกแท็บ **Phaser 3 / Godot 4 / Unity** ด้านล่างหน้าต่างเพื่อคัดลอกโค้ดและขั้นตอนการ Slice ไปวางใน Game Engine ได้ทันที

| คีย์ลัด | การทำงาน |
| :--- | :--- |
| `Space` | เล่น / หยุดแอนิเมชัน |
| `Ctrl + Z` / `Ctrl + Y` | ย้อนกลับ / ทำซ้ำ |
| `ลูกกลิ้งเมาส์ (Scroll)` | ซูมเข้า-ออกบนหน้าจอกลาง (สูงสุด 300%) |
