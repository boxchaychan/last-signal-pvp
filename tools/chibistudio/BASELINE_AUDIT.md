# ตรวจซอร์สจาก ZIP ต้นทาง

ตรวจ HTML ทั้งสามชุด สคริปต์ Python ทั้งในแพ็กเกจหลักและ ZIP ข้างใน รวมถึงข้อมูล Mesh, โปรเจกต์ตัวอย่าง, ภาพ Sprite Sheet, GIF และผล QA เดิม ตรวจด้วยว่า HTML V0.4 ที่บรรจุมาตรงกับ `template.html` หลังแทรก `mesh.json` และ `render.py` ในชุดหลักตรงกับสำเนาที่อยู่ใน Throw Lab

| ส่วน | สิ่งที่ทำงานจริง | ขอบเขตของรุ่นเดิม |
|---|---|---|
| V0.4 + `source/template.html` | เรนเดอร์ภาพจากเมชตอนรันจริง ใช้ interpolation ของแอตลาส 25 โพสที่คำนวณล่วงหน้า มี 3,540 สามเหลี่ยม ท่าผ่อนและท่าปา ท่าจัดเอง PNG, Sheet, บันทึก/โหลด JSON | แอตลาสเก็บเฉพาะไหล่และศอกซ้ายของซุส มือ IK ค้นช่วงมุมของแอตลาส ผ้ากับลำตัวใช้ deformation เฉพาะงานเดิม ขาและสะโพกยังไม่มี Rig จริง |
| `source/build.py`, `render.py`, `test.py` | สร้างเมชและแอตลาส ARAP จากซอร์สภาพ เรนเดอร์เฟรมทดสอบและส่งออกด้วย Playwright | ข้อกำหนดว่าเมชไม่พลิกเป็นการตรวจเชิงเรขาคณิต ยังต้องตรวจเส้นขอบและการเคลื่อนไหวด้วยภาพ |
| Legacy `chibi_studio_v041.html` | โครงกระดูกแม่ลูก แก้ตำแหน่งและมุม นำ PNG เข้าทีละชิ้น Keyframe พรีเซต เปลี่ยนโครงและส่งออก Sheet ได้ | IK ผูกไว้กับมือซ้ายในท่าพัก น้ำหนักเมชปรับเป็นแถวสำหรับการดัดส่วนปลาย ยังไม่มีแปรงหลายกระดูกหรือการรวมกับตัวแก้ซุส |
| Legacy `zeus_throw_lab_v3_package.zip` | `throw.py` แยกมือและสายฟ้าจากชีทพื้นเขียว เรนเดอร์ 36 เฟรมล่วงหน้า หน้า HTML เปิดและส่งออกเฟรมได้ | ตัวเล่นเฟรมที่เรนเดอร์ล่วงหน้า ไม่มีการแก้ Rig หรือ Mesh ขณะรัน |
| ส่วนที่ยังขาดร่วมกัน | — | การประกอบหลายชิ้นพร้อมไกด์และ Snap, Rig และ IK มือ/เท้าครบ, แปรง Weight หลายกระดูก, Slot สีหน้า, คลิปข้ามตัวละคร, ฉากทดสอบต่อสู้, ส่งออก GIF จากตัวแก้ และ APK |

เปิด HTML ทั้งสามชุดจากไฟล์ด้วย Chromium อีกครั้ง V0.4 แสดงผลผ่าน CPU และตรวจซ้ำ 36 ตัวอย่างโดยไม่พบสามเหลี่ยมกลับด้าน หน้าต้นแบบเดิมทั้งสองโหลด Canvas ได้และไม่มี JavaScript page error ในการเปิดครั้งนั้น

V0.5 ใช้ภาพซุส ชิ้นมือ และสายฟ้าที่ให้ไว้ แปลงโปรเจกต์ V0.4 เป็นคลิปใน Rig ใหม่แบบประมาณค่า โปรเจกต์ V0.4.1 แบบ PNG จะนำโครง ตำแหน่งชิ้นส่วนและคีย์การเคลื่อนที่เข้ามา ผลสปริงและรูปทรงการดัดจากรุ่นเก่าต้องปรับใหม่ตามระบบปัจจุบัน
