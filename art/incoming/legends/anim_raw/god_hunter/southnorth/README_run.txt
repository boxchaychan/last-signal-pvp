ARTEMIS | SOUTH + NORTH | Animation Sprite Sheets

Six individual sprite sheets created from generated illustrated sequence art and cropped into uniform game cells.

3a_SOUTH_IDLE.png     4 frames, 2 columns x 2 rows
3b_SOUTH_ATTACK.png   6 frames, 3 columns x 2 rows
3c_SOUTH_SKILL.png    6 frames, 3 columns x 2 rows
4a_NORTH_IDLE.png     4 frames, 2 columns x 2 rows
4b_NORTH_ATTACK.png   6 frames, 3 columns x 2 rows
4c_NORTH_SKILL.png    6 frames, 3 columns x 2 rows

Each cell is 128 x 128 px. Read left-to-right, then top-to-bottom. All PNG sheets have plain white backgrounds.
Each action also has 2x_preview.png (enlarged nearest-neighbor) and GIF loop previews.
Individual 128x128 PNG frames are under frames/<action>/.
References and the six original instruction text files are included.

ARTISTIC ACCURACY NOTE:
These are concept-derived animation samples, not perfectly authored production animation. The original generated art did not separately depict all instructions, so especially the skill's kneeling, three-arrow nocking, upward aim and release remain approximations; the crouch and arrow visibility were edited for clarity. The NORTH pose is three-quarter-back, matching the supplied turnaround's visual style, not perfectly orthographic back. These sheets have not been validated for seamless in-engine playback. The supplied EAST file was not modified.
